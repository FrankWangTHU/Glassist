# Glassist review materials

[Watch or download the live walkthrough (2 minutes 26 seconds)](https://github.com/FrankWangTHU/Glassist/raw/refs/heads/main/docs/submission/Glassist-Walkthrough.mp4)

Updated November 18, 2026. This replaces the earlier still-image walkthrough with real screen recordings of the macOS app and native widgets. Waiting and repeated attempts were trimmed. Zooms and illustrated pointer/click cues were added for clarity; the video labels those cues as editorial additions. The Todoist API token stays masked.

The Quick Add draft was not submitted. Completion was demonstrated with a dedicated review task.

The host app, widget controls and gallery are in English. The native configuration editor in this recording still has some Chinese labels, and the clip shows the saved filter selection but does not clearly capture opening the picker and choosing its entry. An English recording of that step remains outstanding; this revision does not claim that every requested review item is complete.

Users build with their own Xcode account. The recorded local installation uses temporary free Personal Team development provisioning. There is no Developer ID-signed, notarized public installer, and Todoist has not confirmed whether this distribution route meets its certification requirements. Review is pending; Glassist is not certified.
